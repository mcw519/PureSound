Train your own speaker embedding model

# Generate manifest
python -m puresound.dataset.corpus.kaldi --utt2gender_path=utt2gender.txt --insert_root_path=/corpus/path manifest wav2scp utt2spk
# Training
python main.py --training work.yaml

Extract speaker embedding

python main.py --inference --ckpt_path ckpt_path work.yaml

Caculate the EER scores

# Extract embedding for each utterances
python main.py --inference --ckpt_path ckpt_path work.yaml
# Scoring
python local/compute_eer.py eer_trail_file embeddings_folder score_file

Decision threshold

puresound infer, the web app and demo.py accept a trial when the cosine similarity of the two embeddings is above the model's threshold in model_zoo/catalog.yaml: 0.37 for PS-spk-v1-1 and 0.39 for PS-spk-v1. Both were set on LibriSpeech test-clean (40 readers, 2,620 utterances, every pair of utterances a trial) at the point where 1% of trials between two readers of the same sex are accepted, rounded to 0.01. The full record is speaker_threshold_librispeech_test_clean_20261023.json.

LibriSpeech test-clean PS-spk-v1-1 PS-spk-v1
EER, every trial 1.41% (at 0.33) 1.87% (at 0.32)
EER, same reader in two chapters 1.54% 2.03%
EER, first 3 s of each utterance 1.64% 2.11%
1% false acceptance, same-sex impostors at 0.372, 2.5% false rejection at 0.392, 3.9% false rejection
The former default, 0.8 rejects 83% of same-reader trials rejects 83%

Scores are raw cosine similarities. local/compute_eer.py maps them to (score + 1) / 2 for its EER, which leaves the EER unchanged but not what a threshold means. LibriSpeech is clean read speech: noisy, far-field or telephone recordings lower same-speaker scores, so calibrate on such data before relying on these points there:

uv run python local/calibrate_threshold.py LibriSpeech/test-clean \
    --speakers LibriSpeech/SPEAKERS.TXT --out threshold.json

判定門檻

puresound infer、網頁介面與 demo.py 在兩段 embedding 的餘弦相似度高於模型門檻時判為同一人， 門檻寫在 model_zoo/catalog.yaml：PS-spk-v1-1 為 0.37， PS-spk-v1 為 0.39。兩者都在 LibriSpeech test-clean（40 位朗讀者、2,620 段語句，任兩段語句 即一組試驗）上校正，取「同性別的不同朗讀者有 1% 被誤判為同一人」的那一點，四捨五入到 0.01。 完整紀錄見 speaker_threshold_librispeech_test_clean_20261023.json。

LibriSpeech test-clean PS-spk-v1-1 PS-spk-v1
EER，全部試驗 1.41%（門檻 0.33） 1.87%（門檻 0.32）
EER，同一朗讀者的不同章節 1.54% 2.03%
EER，每段只取前 3 秒 1.64% 2.11%
同性別冒充者誤收 1% 門檻 0.372，誤拒 2.5% 門檻 0.392，誤拒 3.9%
先前的預設值 0.8 拒掉 83% 的同一人試驗 拒掉 83%

分數是原始的餘弦相似度。local/compute_eer.py 計算 EER 時會換算成 (score + 1) / 2， EER 不變，但門檻代表的意義會變。LibriSpeech 是乾淨的朗讀語音；嘈雜、遠場或電話錄音會讓同一人的 分數降低，在那類資料上使用前請先重新校正：

uv run python local/calibrate_threshold.py LibriSpeech/test-clean \
    --speakers LibriSpeech/SPEAKERS.TXT --out threshold.json
