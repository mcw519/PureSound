# 聲學世界

[English](world.md)

`puresound web` → **聲學世界**（`#/world`）在房間中放置最多八個講者與噪音源——
每個都可以靜止或移動——渲染一支麥克風收到的聲音，用增強模型處理，再以任務對應的
參考評分。極限地圖則在兩個
參數的格點上重複渲染。渲染器說明見[移動聲源渲染](../algorithms/audio/dynamic_scene.zh-TW.md)。

## 建立場景

在設定中選擇**起始場景**：

| 預設 | 內容 |
| --- | --- |
| 走近再離開 | 目標講者走近麥克風再離開；另一位講者站著不動。 |
| 兩人交換遠近 | 兩位講者穿過房間，交換遠近位置。 |
| 轉頭說話 | 目標講者站在原地，轉身背對麥克風再轉回來。 |
| 走到屏風後 | 目標講者走到擋住直達聲的屏風後方。 |
| 熱鬧的房間 | 目標講者從兩位站著不動的講者旁走過；風扇運轉，一台嗡嗡作響的機器穿過房間。 |

### 聲源

**聲源**底下的 **+ 講者** 與 **+ 噪音** 可新增聲源，最多八個；達到上限時兩者會停用並
說明原因。新的聲源站在距麥克風 1.5 公尺、第一個空著的方位——房間內、障礙物外，且與
其他每個聲源的路徑至少相隔 0.5 公尺——面向麥克風，並帶有自己的音訊（講者輪流使用語音
範例，噪音使用噪音範例）。**×** 會移除聲源；最後一個會保留。

每個聲源都有角色：

| 角色 | 扮演 | 發聲方式 |
| --- | --- | --- |
| 目標講者 | 模型應保留的人 | 像人說話（`speech_human`） |
| 其他講者 | 模型應移除的人，或在**所有語音**中保留 | 像人說話 |
| 噪音 | 噪音源 | 各方向均勻（`omnidirectional`） |

一個場景可以有多個同角色的聲源，也可以完全沒有某個角色。同角色的聲源共用該角色的
顏色，後面的依序變淺，並在平面圖、3D 視圖與播放器中標示 ID。

**靜止不動**讓聲源停在同一處（一個關鍵影格）；關閉時會在場景結尾、同一位置新增一個
關鍵影格，可直接拖曳。噪音也能像其他聲源一樣移動。

每個聲源依關鍵影格移動：時間、位置與面向的方向（方位角；打開**高度與俯仰**可編輯
俯仰角）。可以在平面圖上編輯——拖曳編號的關鍵影格或麥克風；方向鍵把聚焦中的點移動
5 公分（Shift：25 公分），Enter 選取——或在**聲源**底下的關鍵影格表格中輸入。在地面上
按兩下，會把選取的聲源在時間軸目前的時間放到該處：新增關鍵影格，或移動該時間已有的
關鍵影格。聲源底下的**在 … 秒新增關鍵影格**會在既有路徑上新增一個，移動它之前場景
不會改變。位置相同的關鍵影格共用一個標記（「1,3」）。

平面圖依比例繪製房間與 1 公尺格線、麥克風與其周圍的近場區域、障礙物、每條路徑，以及
每個聲源在時間軸目前時間的位置。下方的讀數列出每位講者的距離、偏離麥克風的角度與
近場權重。

其他設定：

- **長度**會等比例縮放關鍵影格時間，讓每個影格維持在場景中的相對位置。
- **種子**決定房間材質（依所選**房間類型**）的抽樣與殘響尾巴。**尺寸**與**麥克風**以
  公尺為單位。
- **參考音**決定參考保留每位講者聲音的哪一部分（見下文）。
- **近場半徑**決定近場區域參考（見下文）。
- 每個聲源有自己的音訊（範例或上傳）、增益、開始時間。講者可選**重播完整語句**，
  噪音則可選**循環播放片段**。語音範例使用完整原始語句，不再使用說話者驗證的半句
  片段；只重播放得完的整段，剩餘時間保持安靜並保留傳播延遲與殘響。若連一次都放
  不下，請延長場景、提早開始，或選用較短的完整錄音。選單會顯示範例秒數。噪音仍
  可填滿最後不足一輪的時間，循環接縫以 10 ms 淡化。`speaker-a-2` 為相容舊場景，
  現在指向與 `speaker-a` 相同的完整語句，不是第三位獨立講者。上傳素材本身也應包含
  完整語句；渲染器不會自動判斷錄音內的句子邊界。

編輯時會依伺服器相同的限制即時顯示問題：關鍵影格在房間外、距麥克風不到 0.2 公尺或
位於障礙物內、影格時間順序錯誤、路徑速度超過 2 m/s。修正之前**渲染**會
停用，原因顯示在按鈕提示中；每次編輯後，伺服器自己的檢查會稍後跟上。

## 渲染與試聽

### 選用 ai-coustics 比較

使用 `uv sync --extra cpu --extra aicoustics` 安裝應用層選用套件，或在目前的伺服器
環境安裝 `aic-sdk==3.3.0`。在設定開啟**與 ai-coustics 比較**，輸入開發者平台提供的
完整 SDK 金鑰，選擇 16 kHz 模型及處理強度。Quail Voice Focus 處理主要講者；
Quail Multi Speaker 與 Rook Multi Speaker 保留多位講者。解讀分數時請選擇符合任務
的參考政策。

同一個 world job 只渲染一次，兩方收到完全相同的單聲道混音與共用場景增益。Python
SDK 以完整區塊處理，補零排出延遲尾段，並依 SDK 查詢結果扣除延遲，保留原始樣本
數。播放器新增 ai-coustics 輸出與移除成分，可勾選比較、切換參考政策、轉寫及下載。
表格列出 SI-SDR、改善量、STOI、PESQ、處理 RTF 與 SDK 音訊延遲。初始化及下載
耗時另外記錄；單次 RTF 並非跨硬體的固定效能指標。

掃描時每格都執行雙方模型。**地圖比較對象**可選 PureSound、ai-coustics 或兩方
SI-SDR 差值（ai-coustics 減 PureSound）。缺少比較分數不視為靜音，也不代表通用
模型失敗門檻。選用服務失敗時仍保留本機模型結果並顯示原因，格子上的**重試**會
重跑該格的場景與雙方處理；重跑保存的比較格子需要重新提供金鑰。

金鑰只留在分頁及執行中的工作記憶體，不寫入歷史、保存的請求、場景 JSON、ZIP、
報告或應用錯誤訊息。程式不會自動改用環境變數中的金鑰；必須明確啟用並輸入。
SDK 在本機伺服器處理音訊，模型下載、授權及用量回報需要網路。模型快取預設在
`~/.cache/puresound/ai-coustics`，可用 `PURESOUND_AIC_CACHE` 指定其他目錄。
每次工作建立新的 processor 狀態並共用已載入權重。報告保存請求與實際模型 ID、
雜湊、SDK 版本、強度、區塊大小與延遲。整合僅位於 `puresound.web`，取樣與訓練
不會呼叫此 SDK。

官方資料：[Python SDK](https://docs.ai-coustics.com/reference/sdk/language-bindings/python)、
[模型目錄](https://docs.ai-coustics.com/reference/sdk/models)、
[金鑰授權](https://docs.ai-coustics.com/models/get-started/authenticate-apps)、
[延遲對齊](https://docs.ai-coustics.com/reference/concepts/latency)。

播放器預設開啟**聆聽**模式，以較大的音軌卡片與波形呈現。打開**顯示音軌**，勾選
要比較的麥克風、模型輸出、參考音或聲源分軌；瀏覽器會記住這個播放器的選擇，重新
整理後也保留。**分析音訊**會展開頻譜、縮放與分析工具，不會攤開未勾選的音軌。
點卡片可在同一播放位置切換聆聽。取消勾選正在聽的音軌時，會切換到另一條已勾選且
載入完成的音軌，並至少保留一條音軌。評分與參考政策收在播放器下方的展開區。

渲染後，3D 視圖會以各聲源的顏色顯示隨音量變化的波紋。亮度與可見擴散範圍依據
麥克風收到的各聲源分軌 RMS 音量，使用共用的 −65 至 −15 dBFS 顯示尺度，因此能
反映距離、遮擋與殘響，不受目前選取的試聽音軌或播放增益影響。波紋是放慢的視覺
提示，並非物理波前模擬。薄柔光球殼取代密集網格，音量快速亮起、以 100 ms 的
釋放時間淡化。播放、暫停與拖曳都跟隨音訊時鐘，聲源移動時，已產生的
波紋留在原本的位置。開啟系統「減少動態效果」時只改變聲源亮度；渲染前不顯示波紋。

**渲染場景**（Ctrl+Enter）會啟動可取消的工作，進度顯示在頁首下方。模型選
**無 · 只渲染房間**即可不套用模型；此時分數描述的是麥克風收音本身。

**評分目標**決定參考，切換時只會重新評分同一次渲染：

- **目標講者**——角色為目標講者的每個聲源。
- **所有語音**——所有講者，不論是否為目標。降噪模型的預設。
- **近場區域**——近場半徑內的所有講者，邊界以 0.2 公尺淡出。人聲分離模型的預設。

選擇模型、預設場景或匯入場景，或從紀錄開啟渲染結果時，會重新套用預設；沒有模型時，
場景有目標講者就用目標講者，否則用所有語音。參考為靜音時——沒有目標講者、近場沒有
人——結果改為報告輸出有多安靜，而不是 SI-SDR。

**參考音**（設定 › 場景）決定參考保留每位講者聲音的哪一部分，名稱沿用訓練管線；
更改後需要重新渲染：

| 參考音 | 保留 |
| --- | --- |
| 早期 · 直達聲 + 50 毫秒（預設） | 直達聲與其後 50 毫秒內的反射 |
| 直達 · 直達聲 + 6 毫秒 | 只有直達聲 |
| 完整 · 含殘響 | 麥克風收到的完整聲音 |
| 無響 · 乾聲 | 位於直達聲抵達時間的乾聲片段，彷彿沒有房間 |

數據列出輸出與麥克風的 SI-SDR、兩者差值、STOI 與 PESQ。播放器可以聽麥克風、模型
輸出、被移除的成分、各種參考與各聲源單獨的收音；下方與音訊對齊顯示每 1 秒視窗的
SI-SDR 變化與每位講者的距離。播放時，平面圖與 3D 視圖中的聲源會跟著移動。需要 WER
時可用逐字檢查轉寫各軌。

**在這台裝置上執行**會在瀏覽器執行同一個模型（見[在這台裝置上執行](web.zh-TW.md#在這台裝置上執行)），
加成一條新軌，並顯示它與伺服器輸出的差異。

## 極限地圖

切到**極限地圖**分頁，為欄與列各選一個參數並輸入以逗號分隔的數值（最多 25 格），再按
**執行掃描**。每個參數讓同類的所有聲源變化相同的量，所以多個聲源之間的差異會保留：

| 參數 | 改變的內容 |
| --- | --- |
| 噪音音量變化 · dB | 加到每個噪音源的增益上 |
| 其他講者音量變化 · dB | 加到每位其他講者的增益上 |
| 目標距離變化 · 公尺 | 把每位目標講者的每個關鍵影格移離（+）或移近（−）麥克風 |

場景缺少參數所調整的那一類聲源時（沒有噪音卻選噪音變化），掃描會被擋下。格子完成後
陸續填入，顯示輸出相對於所選參考的 SI-SDR，以及相對於麥克風的變化。這些參數出現前
做的地圖仍可開啟，顯示舊的參數名稱。底色
深淺只用來比較同一張地圖內的格子。開啟格子即可試聽，失敗或取消的格子可以重跑。極限
地圖需要選擇模型。

## 檔案與 API

**匯出場景 JSON** 保存場景與音訊引用（上傳的音訊必須仍存在）。渲染產生的**場景包**
包含場景、渲染器版本與設定、附 SHA-256 雜湊的聲源音訊、所有渲染音軌與報告；
用**匯入…**載入場景包即可重現渲染。角色出現前存下的場景與場景包也能匯入：原本評分的
講者成為目標講者，其他講者成為其他講者。

- `GET /api/world`——預設場景、房間類型、範例音訊、限制（角色、參考類型、聲源數）、
  掃描參數與各自調整的角色，以及各任務預設的參考。
- `POST /api/world/validate`——`{scene, assets}`；回傳正規化後的場景或錯誤。
- `POST /api/world/materials`——`{scene, room_type}`；回傳依房間類型與場景種子重新
  抽樣材質的場景。
- `POST /api/jobs`，帶 `kind: "world_render"` 或 `"world_sweep"`、`scene`，以及可選的
  `assets`、`model_id`、`provider`；掃描另帶兩個 `axes: [{parameter, values}]` 與可選的
  `cell_indices`。以 `GET /api/jobs/{id}?summary=1` 輪詢（掃描進行中會回傳每格的狀態
  與 SI-SDR），取消方式與其他工作相同；完成的工作可匯出包含所有音軌的 ZIP。

```python
from puresound.audio.rir.scene.world_presets import world_preset
from puresound.audio.rir.render.dynamic import render_dynamic_scene
scene = world_preset("approach", seed=4)
render = render_dynamic_scene(scene, assets)  # 依 asset_id 對應的 16 kHz 單聲道陣列
```

測試：`test/rir/test_dynamic_scene.py`、`test/rir/test_rir_path_band_effects.py`、
`test/web/test_world.py` 與 `test/web/world_model.test.cjs`。
