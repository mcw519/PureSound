How to run it

In your browser

Nothing to install: run the released models on your own audio.

Try it

From the command line

Process files with one command after installing with uv or pip.

uv run puresound infer voice-isolate-dpcrn-curriculum-v1 --input audio=in.wav --output audio=out.wav
Install guide

In a local web app

Compare models, record from a microphone and inspect the results on your own machine.

uv run puresound web
