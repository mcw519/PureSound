# Pipeline inspector samples

Built by `tools/build_pipeline_samples.py`; do not edit by hand.

Talkers: the playground's LibriSpeech clips one folder up (Panayotov et al., 2015),
CC BY 4.0. Noise: synthesised by the build script from a fixed seed; the babble is
those two readers, time-reversed. Rooms: impulse responses and geometry from one of
PureSound's own synthetic RIR banks. No other recording is included.
